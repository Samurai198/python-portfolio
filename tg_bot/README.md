# Telegram-бот для приёма заявок

Бот для малого бизнеса: салон, мастер, ремонт, доставка, любые услуги.
Клиент оставляет заявку в пару нажатий, владелец сразу получает её в личку.

## Как это выглядит

1. `/start` → кнопки «Оставить заявку» и «Цены и контакты»
2. Бот спрашивает имя → телефон (можно одной кнопкой) → услугу
3. Телефон проверяется, услуга выбирается только из списка
4. Владелец получает сообщение:

```
🆕 Новая заявка

Имя: Анна
Телефон: +79001234567
Услуга: Маникюр
Telegram: @anna
```

## Запуск

```bash
pip install -r ../requirements.txt
export BOT_TOKEN="токен от @BotFather"
export ADMIN_ID="ваш id от @userinfobot"
python bot.py
```

Под нового клиента меняются список `SERVICES`, текст с ценами и шаги опроса.
Стек: Python 3.11, aiogram 3 (FSM для пошагового диалога).
