# Парсер каталога товаров

Собирает с сайта название, цену, наличие, рейтинг и ссылку на каждый товар.
Результат сохраняет в **CSV** (открывается в Excel) и **XLSX**.

Для демонстрации используется учебный сайт [books.toscrape.com](https://books.toscrape.com).
Под другой сайт нужно поменять `BASE_URL` и CSS-селекторы в `parse_page()`.

## Запуск

```bash
pip install -r ../requirements.txt
python parser.py --pages 5 --out books
```

## Что умеет

- проходит по страницам пагинации и останавливается, когда они заканчиваются
- делает паузу между запросами, чтобы не нагружать сайт
- CSV сохраняется с `;` и BOM, поэтому кириллица корректно открывается в Excel
- есть тест разбора HTML: `pytest`
