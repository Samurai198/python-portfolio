# Автоотчёт по продажам в Excel

Превращает «сырую» таблицу продаж в готовый отчёт за одну команду.
Вместо ручных сводных таблиц — один запуск скрипта.

## На входе

CSV или XLSX с колонками `date, manager, product, qty, price` (пример — `sales.csv`).

## На выходе

`report.xlsx` с листами:

| Лист | Что внутри |
|---|---|
| Менеджеры | число сделок и выручка по каждому, от лучшего к худшему |
| Товары | продано штук и выручка по каждому товару |
| По месяцам | выручка помесячно |
| Данные | исходная таблица + посчитанная выручка |

Заголовки выделены, ширина колонок подобрана автоматически.

![Листы отчёта](../docs/excel_report.png)

## Запуск

```bash
pip install -r ../requirements.txt
python report.py sales.csv --out report.xlsx
```
